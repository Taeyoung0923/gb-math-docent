칠곡 수학문화관 · 경북 6콘텐츠 · 카발리에리 자매 — 입체(3D)

입체도형 단면의 넓이비가 같다면 부피비도 같다고?

🫀 이 전시물의 심장
"부피가 같다"를 말해주는 곳이 아니라, 학생이 막대로 탑을 기울인 뒤 — 층층이 쌓인 보이는 단면(판)을 보고, 밑면이 달라 보여도 모든 높이의 단면이 짝맞음을 스스로 확인하는 곳.
콘텐츠 ID: CHG-02 · 운영모드: 모드 A(도슨트 동반) · STAGE4 통합 v1.0
⚠ 7월 칠곡 현장확인 전 설계본 — 같은 높이 기준선·측정 가능성·그래프 가림은 방문 시 확정

📷 전시물

실제 전시물 모습 (사각뿔 ↔ 원뿔, 얇은 판 적층, 막대로 기울임)

⚠ 도슨트 이해용. 학생에게 사진·정답을 먼저 들이밀지 마세요 — 발견은 학생 몫.

🎯 도슨트가 외울 단 하나

시선을 기울어지는 겉모양에서 층층이 쌓인 단면으로 옮긴다.

발문은 "신기하니?" ❌   "같은 높이 판은 어때?" ✅
명명·그래프는 학생 발견 직후에만.

핵심 흐름

1 직관탐색 (~3분) — 밀어서 기울이기 실컷 · 변화 구경 길게(입체)
2 발견유도 (~12분) ★심장 — "같은 높이 판?" → 단면 직접 관찰 → 부피 불변 자가발견
3 형식화 (~10분) — 발견 직후 카발리에리·그래프 공개 → 다른 모양 같은 부피 창조
4 전이 (~5분) — 평면(선·넓이)↔입체(판·부피) 동형 · 적분/CT 씨앗

🚫 절대 금기 4가지

  • 우측 설명·그래프 먼저 노출 → 가렸다 발견 후 공개.
  • "판 안 변했죠?" 답 말하기 → 방향만, 발견은 학생.
  • 변화 구경(WT-III)을 평면처럼 짧게 → 입체는 더 길게.
  • "각진·둥근 탑 왜 같냐"를 "원래 그래요"로 봉합 → 반드시 층층 단면 짝맞춤으로.

🫀 이 전시물의 고유 엔진

학생의 눈은 움직이는 것(막대→입체 모양)에 빨려든다. 그런데 부피 보존의 비밀은 눈에 보이게 쌓인 판(단면) 하나하나가 그대로라는 데 있다.

평면 형제와 동일 구조, 차원만 한 단계 위

평면(2D 형제)입체(3D·이 전시물)
쌓는 단위선분(1D)판/원판(2D 단면)
보존되는 것넓이부피
학생이 보는 불변같은 높이 선분 길이같은 높이 단면(판) 넓이
엔진자로 직접 측정보이는 판 직접 관찰
왜 "직접 관찰"인가
사진상 사각뿔·원뿔이 얇은 판을 켜켜이 쌓은 가시적 적층이다. 단면이 숨어 있지 않고 눈에 보인다. 그래서 "예측하고 확인"이 아니라 "보고 확인"이 자연스럽다.

⛔ 측정 가능성(판 넓이를 자로 잴 수 있는지)은 7월 현장확인. 그때까지 엔진은 "관찰"까지 확정.

⚠ 그래프·설명 가림 — 전 단계 공통 사전 처리

안내판 우측에 카발리에리 설명문 + 그래프 도식(A·B·C·D, m:n)이 노출돼 있다. 평면과 같은 "정답 누설" 구조.

🟨 도슨트 가림 동작 (시도)
  • 1·2단계 동안: 우측 설명·그래프를 잠깐 가림, 또는 "오른쪽 어려운 글은 잠깐 비밀로"로 봉인
  • 공개 시점: 학생이 "같은 높이에선 판이 그대로네"를 스스로 말한 직후

1직관적 탐색 — 놀이터

무형식~3분

전략: 막대를 밀어 사각뿔→빗뿔, 원뿔→빗원뿔로 기우는 변화를 실컷 보게 둔다.

WT-III 길게 — 평면보다 길게. 입체는 기울 때 더 입체적으로 변해 신기함이 오래 간다.

어포던스 발문

  • "막대를 잡고 밀어보세요. 이 뾰족한 탑이 어떻게 되나요?"
  • "두 개(각진 탑·둥근 탑) 다 밀어보세요. 어떻게 달라져요?"

❌ 금지: "판이 몇 장인지 세보세요" — 아직 변화 소진 전.

2발견 유도 — 비밀 규칙 찾기 ★심장

비형식~12분

전략: "신기해?"❌ → "같은 높이에서 잘라보면?"✅. 보이는 판을 지목이 아니라 비교로 끌어낸다.

MLE 3박자

① 입력 — 기준 고정: "밀기 전 이 탑 모습, 눈에 담아두세요." / "이 탑은 무엇으로 만들어졌나요?"(판 인지)

② 정교화 — 보이는 단면 직접 관찰: "탑이 비스듬해졌죠. 그런데 판 한 장 한 장을 보세요 — 같은 높이에 있는 판은 크기가 변했나요, 그대로인가요?"(3초) / "각진 탑과 둥근 탑, 같은 높이에서 판을 비교하면?"

🔑 결정적 순간: 학생이 "비스듬해져도 같은 높이의 판은 그대로"를 눈으로 직접 확인하는 순간이 심장. 도슨트가 말하면 죽는다.

③ 출력 — 언어로 연결: "겉모양이 변했어요"(1차) → 한 박자 더 → "...근데 판들은 그대로 쌓여 있네?"(2차) → "판이 다 그대로면, 합친 부피는?"

3형식화 및 창조 — 패턴 마스터

형식~10분

⚠ 여기서 가렸던 우측 설명·그래프 공개.

명명 연결: "여러분이 본 것 — 같은 높이의 단면이 같으면, 모양이 달라도 부피가 같다 — 이걸 수학자 카발리에리가 발견했어요." → 그래프 공개. "A·B, C·D가 바로 같은 높이에서 자른 단면이에요."

순서 엄수: 발견 → 명명/그래프. 거꾸로 가면 전부 무너진다.

🟨 창조 도전: "모양은 완전히 다른데 부피가 같았어요. 또 다른 모양인데 부피는 같은 탑을 상상해 만들 수 있을까요?"

4전이 및 연결 — 세상 속 패턴 사냥

전이~5분

🔗 자매 연결 (역방향 다리): "납작한 형제(옆 전시물)에서는 선을 쌓아 넓이를 봤어요. 여기선 판을 쌓아 부피를 봤고요. 무엇이 같고 무엇이 한 단 올라갔나요?"

심화 전이: "이 '얇은 조각을 무한히 쌓기'는 나중에 수학에서 적분(∫)이 돼요. 적분의 할아버지를 오늘 만진 거예요."

본질질문 마무리: "모양이 이렇게 다른데, 어떻게 부피가 같을까? 무엇이 끝까지 그대로였나?"

📑 5종 카드 지도

카드대상도달 목표관찰 도구
①유아·초등저탑이 기울어도 판은 그대로눈·손가락
②초등고 ★같은 높이 단면 같으니 부피 같다눈+손가락 높이맞춤
③중학생단면 비 → 부피 비 설명관찰+비례추론
④고등·성인단면적분 = 부피 모델링극한·적분 직관
⑤가족부모=진행자, 아이=관찰자역할 분담
① 유아·초등저 — "탑이 비뚤어졌네!"

도입: "막대를 밀어볼까요? 뾰족한 탑이 어떻게 됐어요?" / "이 탑은 무엇이 쌓여서?"

심화(신체): "손가락으로 맨 아래 판을 짚어볼래요? 밀어도 작아졌어요, 그대로예요?" / "각진 탑·둥근 탑, 똑같은 높이에 손가락을 대보세요. 판들이 비슷해요?"

② 초등고 — "같은 높이 판은 진짜 같을까?" ★표준

도입: "탑이 비스듬해져요. 겉모양 말고, 판들은요?"(3초) / "밀기 전 모습 담고, 밀어봐요."

심화: "같은 높이에 있는 판을 보세요. 변했나요, 그대로?" / "각진·둥근 탑, 같은 높이에서 비교하면?"

연결: "판이 다 그대로면, 합친 부피는?"

③ 중학생 — "왜 부피가 같은지 말로 설명해봐"

도입: "모든 높이 단면이 같으면 부피 같다 — 항상 그럴까요?" / "단면 비가 모든 높이에서 1:1이면, 부피 비도? 2:1이면?"

심화: "사각뿔과 원뿔은 밑면도 다른데 부피가 같을 수 있나요? 단면을 보면?" / "친구에게 어떻게 설명할래요?"

④ 고등·성인 — "이게 적분이다"

도입: "무한히 얇은 단면의 더미로 본다면?" / "단면 넓이를 높이마다 다 더하면? → 부피 = ∫A(h)dh"

심화: "전단(빗뿔)이 왜 부피를 보존하는지 단면으로?" / "카발리에리(1598~1647), 조긍지(1100년 앞서 구 부피)."

연결: "이 '단면 쌓기'가 CT·MRI(단면 영상으로 입체 재구성)와 어떻게 닿아 있을까요?"

⑤ 가족 — "부모는 공동 진행자"

부모 코칭: "정답 대신 '같은 높이 판은 어때?'만 던져주세요." / "답을 참고 기다려 주세요." / "'비뚤어졌어!'라면 '그래도 판들은?' 한 번만 되물어 주세요."

🚫 부모 함정: "이건 부피가 같은 거야" 선언 → 발견 죽음.

🎭 상황 시나리오 8개

★ = 이 전시물 고유 엔진 위에서 표준을 반전시킨 시나리오

S1 — "이게 뭐예요?" 시작법 모름

추천: 조작부만 가리키고 손 뗀다. "막대를 밀어보세요." 침묵.

❌ "부피가 안 변하는 걸 보여줘요" — 시작 전 결론 누설

S2 — "다 해봤어요" 빨리 떠남

판단: ⚠ 자연스러운 신호. 입체는 변화가 화려해 전경에 더 오래 머묾 → 전환 타이밍 놓치지 말 것.

추천: "겉모양은 비뚤어졌는데 — 판들은요? 같은 높이끼리 보면?"

★ S3 — 그래프·설명을 먼저 읽어버린 학생

추천: 글을 부정 말고 검증 과제로 환수. "그 말이 진짜인지, 우리 판으로 직접 확인해볼까요?"

❌ "그거 보면 안 돼요". 글을 디딤돌로.

S4 — "우리 아이가 안 해요" 촉진형 부모

추천: 부모를 공동 진행자로. "정답 대신 '판들은 어때?'만 던져주시겠어요?"

S5 — 단체 혼잡

추천: 1명 밀기 / 2~3명 같은 높이 판 비교 / 나머지 "각진·둥근 탑 짝 맞나" 관찰. 30초 교대.

★ S6 — "각진 탑이랑 둥근 탑이 왜 같아요?"

판단: ⚠ 막힘이 아니라 금광. 입체 전시물의 가장 깊은 의문 — 평면엔 없던 고유 충돌. 이 불신을 환영.

추천: 답하지 말고 단면으로 되돌린다. "밑면만 보면 그렇죠. 그런데 중간·윗부분 높이의 단면도 비교해볼까요? 한 층 한 층 짝이 맞나요?"

❌ "원래 그래요" / "공식이 그래요"로 봉합. 직접 단면 짝맞춤으로만 풀려야 발견이 산다.

★ S7 — "부피 같은 거 이미 알아요"

추천: 심화의 정반대 — 아는 것을 흔든다. "두 탑은 밑면도 옆모습도 다른데 왜 부피만 같죠? 어디서 '같음'이 만들어져요?" / "비스듬히 밀면 옆에서 더 커 보여요. 왜 눈은 속는데 부피는 그대로일까요?"

S8 — 접근성·특별한 요구

추천: 관찰을 촉각·언어로 대체. "이 높이 두 판을 만져보세요. 두께·크기가 비슷해요, 달라요?"

도슨트의 일은 "부피가 같다"를 말해주는 것이 아니라, 시선을 기울어지는 겉모양에서 층층이 쌓인 단면으로 옮겨, 밑면이 달라 보여도 모든 높이의 단면이 짝맞음을 그가 직접 보게 하는 것.

침묵이 필요한 순간 — 채우고 싶을 때, 빨리 마무리하고 싶을 때 — 입을 여는 대신 다문다.
