# 경북 수학체험센터 · 여섯 전시물 도슨트 가이드

칠곡·경산 수학체험센터 여섯 전시물의 도슨트 해설 가이드입니다.
한 장 안내판(필드맵)에서 카드를 누르면 각 전시물의 상세 가이드가 열립니다.

## 보는 법
- **시작 페이지**: `index.html` (GitHub Pages 주소로 접속하면 자동으로 열립니다)
- 카드를 누르면 해당 전시물 가이드로 이동
- 카발리에리는 평면·입체 선택 페이지를 거칩니다

## 여섯 전시물
| 전시물 | 위치 | 유형 | 도슨트 자리 |
|---|---|---|---|
| 구면투영 | 칠곡 | 관찰형 | 꼭 곁에 |
| 제논의 역설 | 경산 | 추론형 | 꼭 곁에 (최강) |
| 3D 공룡 착시 | 경산 | 지각형 | 대체로 곁에 |
| 카발리에리 원리 | 칠곡 | 측정/입체 (자매) | 곁에 동반 |
| 메탈퍼즐 | 경산 | 조작형 | 무대 밖 (무인 기본) |

## 폴더 구성
```
index.html            시작 안내판
guides/
  spherical.html      구면투영
  zeno.html           제논의 역설
  dino.html           3D 공룡 착시
  cavalieri.html      카발리에리 선택 페이지
  cavalieri_2d.html   카발리에리 평면
  cavalieri_3d.html   카발리에리 입체
  metal.html          메탈퍼즐
```
